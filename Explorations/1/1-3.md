# CS 361 - Exploration 1.3: Naming Things

## Why does having good variable names help human code readers?

Good variable names reduce the time it takes for new members of a team to be oriented with the code base. It also reduces the opportunity for costly mistakes to be made by said new members, or old ones. Reducing confusion with the purpose of each variable is essential to ensuring a smooth workflow.

## Speculate on why having good variable names helps AI maintain and understand code.

Using good variable names probably helps reduce the need for additional context that bloats the context window of an LLM model, like comments or commentary in a .md file. Otherwise, the AI would probably need to tokenize the surrounding context which would also bloat the context window and cost tokens.
