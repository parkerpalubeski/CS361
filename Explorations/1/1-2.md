# CS 361 - Exploration 1.2: Code as a Craft

## Between the time you first learned to code and today, what are some of the areas you've improved in with respect to your own code quality?

My code has improved most prominently in readability. Good variable/function naming has been essential to ensuring that produced code is understandable and modifiable. I also think it's improved substantially in modularity. Keeping functions specific and limited in scope makes them much more reusable than attempting to one-shot an entire part of the program with a function.

## Why do you think clean, well-crafted code is cheaper for an AI to maintain?

AI (and especially newer reasoning models) tend to spend tokens talking to itself to understand a problem. Code with comments might spare the AI the need to tokenize the entire function if the purpose, inputs and outputs are clearly outlined.
