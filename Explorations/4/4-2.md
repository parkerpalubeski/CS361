# What's the difference between a class variable and an instance variable?
A class variable is a variable that belongs to the class itself and is static, and unchangeable. An instance variable can be changed on construction, and is bound to the object instead of the class.

# You have a class variable x and 120 instances of the class. How many different xs are there?
There is one x

# You have an instance variable y and 120 instances of the class. How many different ys are there?
There are 120 y's

# Research: why do many devs consider multiple inheritance to be best avoided?
Multiple inheritance can cause significant ambiguity (which parent do I inherit method foo from?) if they both inherit as well (aka the diamond of dread). It's also looked down upon because there are alternatives that are generally considered superior, like composition, if multiple objects must be related.
