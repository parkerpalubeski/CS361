# CS 361 - Exploration 2.5: Use Cases

## Speculate on the usefulness of writing use cases from a human coding perspective.
Use cases from a human perspective would help especially with the usability of the application. Understanding the purpose the app serves would be critical for making UI/UX decisions, as well as ensuring that important information is easily accessible to the user. It also ensures that the project has clear boundaries on what it can achieve and what isn't necessary. 

## Speculate on the usefulness of writing use cases from an AI coding perspective.
Use cases give the AI critical context that it would have trouble interpreting otherwise. A simple description of a project can be highly ambiguous, and the AI might hallucinate or implement things in a way that is suboptimal. A use-case set can make ambiguous information much more specific and enactable for an LLM.
