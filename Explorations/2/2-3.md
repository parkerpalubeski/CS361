## What is an example of code you've written that violates any of the above guidelines? Name the violation and paste in the code.

I have violated the maintainability guidelines several times. Sometimes an assignment just needs to get in, or I get impatient and want to see the program function in practice already.

The example provided for Abstraction reminded me of some habits I had when I first started, when main() would basically hold everything. One example was a Command-Line Battleship game I made as a project years ago. All of the initialization of the board and pieces were done in main(), which was an awful design choice in hindsight.

## What is another example? I know you have more than one. 😊

I don't have another one that I can recall as specifically as the above example, but I know that I have violated the Boolean Parameters guidelines quite a few times. I can vaguelly recall some functions with a structure like so:

```
int example(bool valid){
    if valid{
        [LOGIC]
    }
    else{
        [OTHER LOGIC]
    }
}
```

And it probably would have been better to instead place this code whereever `example` was being called and, in place of [LOGIC] and [OTHER LOGIC], have two different function calls and and place the logics in those functions instead.
