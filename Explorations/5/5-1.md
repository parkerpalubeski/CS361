# Describe differences between an ER diagrams and class diagrams, though they appear to contain much of the same information.

ER Diagrams are typically used for databases, while Class diagrams are for OOP.

ER Diagrams don't contain things like methods since Databases don't contain that either. OOP does have methods, so they are contained within Class Diagrams.

In OOP, access control is often controlled externally, so Class diagrams display this with +, -, etc. In Databases, these are usually handled by the DBMS from the outside, or even by the program querying the database, so they don't need to display access control in the diagram.

# What does public and private mean in OOP parlance?

Public and Private are access variables that determine how a member of a class can be accessed and modified. Public can be accessed outside of the class, such as in the main function of the program. Private can only be accessed by modifiers within the class, such as methods.

For instance. A public attribute balance in a bank account can be modified like so:

account.balance = 2000

But if the method was set to *private*, it would require a public method to modify like so:

account.setbalance(2000)

And this allows you do to things like validate input or change the code later on.
