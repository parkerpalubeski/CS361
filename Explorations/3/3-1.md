# CS 361 - Exploration 3.1: UX Flow

# Name at least three benefits, from a software engineering perspective, of drawing out a UX flow diagram? What does it buy us? What problems might it expose?

* UX Flow diagrams allow us to map out the user-facing part of a program, sort of allowing us to put ourselves in the shoes of the user
* UX Flow diagrams might expose lengthy or convoluted pathways to certain information. Combined with user stories, it allows us to make preliminary considerations for user demands before there is any testing conducted
* It serves as a kind of pre-prototype that we can use to direct our prototyping stages.
