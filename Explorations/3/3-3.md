# CS 361 - Exploration 3.3: Prototypes

## What are the benefits of a functional prototype versus static screens?

Functional prototypes show the flow between screens. Which buttons navigate where?

It allows you to see how users interact with the program, and make adjustments if there are certain elements that generate friction for the user.

## What are the benefits of being able to iterate quickly on a prototype?

This might allow you to adjust the prototype while receiving live feedback, as well as just a quicker development time in general.
